## 这是一个持续更新的个人知识站点

这里不会只放教程摘要，而是把做事过程、技术判断、踩坑记录和长期思考都沉淀下来。

### 你会看到的内容方向

- AI 工具与工作流
- 编程问题与实践笔记
- 算法学习与题解
- 架构设计与技术选型
- 项目管理与协作方法

### 站点的第一阶段目标

1. 先用 IP 跑通手工部署
2. 继续补首页栏目内容
3. 确认域名后再接 HTTPS
4. 后续再决定是否要做自动发布

## 首页主推栏目

### AI

这里会持续记录 AI 工具、提示词、工作流和模型接入经验，重点不是追热点，而是沉淀真正能复用的方法。

### 编程

围绕前后端开发、工程实践、调试过程和项目实现写清楚每一步，尽量让内容既能看懂，也能直接照着做。

### 算法

算法内容不会只停留在题解本身，还会补上思路拆解、复杂度判断和为什么这样做更稳。

### 架构

当项目从能跑走向能长期维护时，架构判断才真正有价值。这一栏会记录系统设计、技术选型和演进过程。

### 项目管理

不仅写代码，也写推进代码的方式：任务拆解、节奏控制、协作方法、上线前检查和复盘。

## 三阶段学习路径

### 第一阶段：零基础入门

如果你还在“知道一点，但不知道怎么串起来”的状态，这里会先帮你建立最短闭环。

- 从想法到页面原型
- 从工具到工作流
- 从本地开发到第一次上线

### 第二阶段：初中级开发

这一阶段开始进入真正的项目交付，重点是把一个看似能跑的东西，变成结构清晰、能持续维护的东西。

- 页面和路由结构
- API 与数据流
- 自动化部署
- 项目拆解与推进

### 第三阶段：高级开发

当项目进入复杂协作和长期维护后，真正的难点不再是“怎么写”，而是“怎么稳定演进”。

- AI 工程化
- 架构演进
- 监控与成本
- 技术债治理

## 用户故事

这个栏目会记录真实的成长和项目过程，不讲“逆天改命”式叙事，只讲具体问题、具体决策和具体结果。

- 从不会部署到第一次上线
- 从单点尝试到形成自己的工作流
- 从混乱执行到可复盘的项目推进
