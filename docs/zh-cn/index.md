## 这是一个持续更新的个人知识站点

这里不会只放教程摘要，而是把做事过程、技术判断、踩坑记录和长期思考都沉淀下来。

### 你会看到的内容方向

- AI 工具与工作流
- 编程问题与实践笔记
- 算法学习与题解
- 架构设计与技术选型
- 项目管理与协作方法

### 站点的第一阶段目标

1. 先用 IP 跑通手工部署
2. 继续补首页栏目内容
3. 确认域名后再接 HTTPS
4. 后续再决定是否要做自动发布
