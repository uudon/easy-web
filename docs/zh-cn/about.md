# 关于我

我是施行。

这个站点不是为了堆砌内容，而是为了把长期做事过程中真正有价值的部分留下来。很多时候，难点不在“有没有知识”，而在“能不能把知识变成自己的工作流”。所以这里会持续记录：

- AI 工具如何进入真实工作
- 编程问题如何被拆解和落地
- 算法学习如何从刷题走向方法
- 架构判断如何影响长期维护
- 项目管理如何决定执行质量

## 这个站点会怎么写

我更关心这些内容：

- 一个问题为什么这样拆
- 一个方案为什么这样选
- 一次上线为什么会出问题
- 一次复盘为什么值得保留

如果一篇内容不能帮人更稳定地做事，它大概率就不值得停留太久。

## 适合谁

- 正在学习 AI、编程、算法的人
- 想把零散知识串成完整方法的人
- 想做项目，也想把项目做得更稳的人

## 这站下一步会继续补什么

- 更完整的首页栏目页
- 真正的文章归档和专题页
- 正式域名与 HTTPS
- 更接近个人站的视觉风格
