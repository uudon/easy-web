# 算法

算法这一栏不会只写答案，更关注“怎么形成自己的方法库”。

## 这个专栏在解决什么问题

很多人学算法都会遇到几个典型困境：

- 刷了很多题，但没有真正积累下来
- 看完题解觉得懂了，过几天又不会
- 只会记答案，不会判断题型
- 不知道什么时候该暴力、什么时候该优化

这一栏就是想把这些问题拆开讲清楚。
