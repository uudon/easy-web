# 项目管理

项目管理这一栏不是写流程名词，而是写“怎么让事情真的往前推进”。

## 这个专栏会写什么

- 需求怎么拆才能执行
- 节奏怎么设才不会只剩焦虑
- 怎么把模糊目标变成明确动作
- 复盘怎么做才不会流于形式
